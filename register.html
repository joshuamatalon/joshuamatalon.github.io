Data consolidation · Excel and CSV · sample deliverable

Consolidation register. Four lists become one, and nothing disappears.

Four departments kept their own supplier lists: two Excel files and two CSV exports, with different column names and orders, four date formats, five phone formats, all-caps company names in one, trailing spaces in another, category codes in a third, and a blank row and a totals line that were never meant to be data. This register merges them into one standard set of columns, keeps every row, and writes down everything it was unsure about. Duplicates are grouped, not deleted. Questionable values are kept as sent and logged.

What was standardised

  • Column names to one set, from four different vocabularies. Company names from all-caps to title case, with "LLC" and "Inc." kept as written.
  • Phones to one format from five; dates to one from four; payment terms from "Net 30" and "30" to a number; category codes expanded to names; whitespace trimmed.

What was not done

  • No value was corrected by guessing. A phone with five digits stays as sent and is listed. A date that cannot be parsed is left blank and listed with the original text.
  • No duplicate was resolved by the script. Which record wins is the owner's call, so both are shown.

How it is built

  • Five tabs: About, Register, Duplicates, Questionable, Sources. The Sources tab reconciles: rows read equals rows kept plus rows excluded, for every file.
  • The build ends with its own check: it fails if any row is lost, if any planted defect is missed, or if anything but the two junk lines was excluded.
