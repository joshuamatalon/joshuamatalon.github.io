Pass Chart. The passing sheet, the arithmetic, and the trend, on one screen.

Volleyball coaches grade every serve-receive pass on a 0 to 3 scale, on paper, then spend the evening adding it up. Pass Chart takes the taps live, or reads the paper sheet from a photo, and turns a season of practices into a rating and a trend per passer. Built for the same club as Courtside.

What it does

  • Grades on a 0 to 3 or 0 to 4 scale, per player, per practice, with passer rating, perfect-pass percentage, good-or-better percentage, and error percentage.
  • Undo for the last tap, a correction path for a whole photo read, and a CSV export of the season for anyone who wants the raw counts.
  • Roster by paste: the whole list at once, jersey numbers optional. The deployed page ships with placeholders so no real names are ever published.
  • Names on the photographed sheet are matched to the roster by exact name, first name, or jersey number, and a row that matches nobody is skipped and shown, not guessed.

How it is built

  • One HTML file, vanilla JavaScript, installable as a progressive web app. Same storage design as Courtside: synchronous local save on every tap, IndexedDB mirror for rescue.
  • The photo path calls a vision model through the coach's own key, entered once on the phone. Offline photos queue and process when signal returns. Everything else runs with no network at all.
  • Every claim in the README was tested in a real browser and the suite is in the repository, so the proof can be re-run by anyone.
