Courtside. A match tracker a coach can run with one thumb.

A volleyball coach on the bench is keeping score, tracking which of six rotations the team is in, counting substitutions against a per-set limit, and trying to remember who just got the kill. Courtside does all of that from one phone, with no signal, and shows the coach where everyone should be standing. Built for a youth club's coaching staff, and they use it.

What it does

  • Season. Every match is kept. Starting a new one never touches the last one; switching between them is one tap on the match bar.
  • Track. Point US or Point THEM every rally. Sideout scoring is implemented exactly: you rotate only when you win a rally you were not serving. Verified exhaustively for all six rotations.
  • Stats. A full box score with the attempts behind every percentage. The pass average is broken into how many passes graded each way, so a 2.4 is not a mystery.
  • Lineup and subs. 5-1, 6-2 or 4-2, positions per match, substitutions counted against the limit, and the live lineup updates so the diagram stays truthful.
  • Scout. An opponent card per team: key players with tendencies, plus free notes, kept season to season.
  • Roster. Names, numbers, positions, and a JSON backup that moves between phones.

The part I am proudest of

The coach can ask for a change from inside the app, in his own words. The request becomes a work item, gets built and tested automatically, the app updates itself on his phone, and the reply comes back to the same screen he typed on. Since August the club's coach has commissioned features this way without messaging me once. The most recent one, an opponent scope on the stats table so he can total every match against the same team, shipped on September 6.

How it is built

  • One HTML file, vanilla JavaScript, no framework and no build step. It runs from a static host and installs as a progressive web app on iPhone and Android.
  • Every tap is written synchronously to local storage and mirrored to IndexedDB, so a crash mid-rally loses nothing and a wiped browser store restores from the mirror. Tested by wiping it.
  • The deployed page ships with a generic roster on purpose. Real names are typed once on the Roster tab and live only on that phone; a public page never carries a team's players.
  • A browser test suite of one hundred assertions covers the scoring rules, rotation arithmetic, statistics, persistence, and the backup format.

Shares its whole design system with Pass Chart: same palette, type scale, spacing and components, so a coach who knows one knows both.
